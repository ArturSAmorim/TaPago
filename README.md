# 🏋️‍♂️ TáPago - App de Acompanhamento de Treinos

O **TáPago** é um aplicativo Android desenvolvido para ajudar usuários a organizarem e acompanharem suas rotinas de treinos de forma simples e intuitiva.

## 📱 Telas e Funcionalidades

- 🔐 **Autenticação:** Tela de Login completa para acesso do usuário.
- 📋 **Lista de Treinos:** Visualização dos treinos e focos de cada dia.
- ⏱️ **Cards de Exercício:** Exibição detalhada com séries, repetições, carga e tempos de execução e descanso.
- ✅ **Cálculo Automático:** Cálculo do tempo total estimado de cada treino.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Kotlin](https://kotlinlang.org/)
- **Interface:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material Design 3)
- **Arquitetura:** MVVM com `ViewModel` e `StateFlow`
- **Ferramenta de Build:** Gradle
